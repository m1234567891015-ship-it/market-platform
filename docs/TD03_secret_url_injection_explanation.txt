TD-03 Redis URL 注入方式說明
================================

目的
----
TD-03 staging wrapper 不把 Redis URL 寫死在程式碼，也不要求將含有帳號或密碼的 URL
貼在對話中。執行前，由本機 shell 或 CI/CD secret store 注入環境變數：

    MARKET_PULSE_REDIS_URL

wrapper 會讀取這個環境變數，傳給測試子程序，但不會把 URL 輸出到畫面、log 或證據文件。


一、本機 PowerShell 執行
------------------------

1. 在目前 PowerShell process 設定 URL：

    $env:MARKET_PULSE_REDIS_URL = "<你的 staging Redis URL>"

2. 執行 TD-03 wrapper：

    powershell -NoProfile -ExecutionPolicy Bypass -File regression\td03_run_staging.ps1

環境變數會由目前 PowerShell 傳給 wrapper 及其 Python 子程序。關閉目前 PowerShell 後，
這個 process-scoped 變數通常不再存在。

本機測試可使用：

    $env:MARKET_PULSE_REDIS_URL = "redis://127.0.0.1:6391/1"

正式 staging 不應使用本機 URL，應使用隔離的 Redis／Valkey staging instance。


二、CI/CD Secret Store 執行
---------------------------

1. 在 CI/CD 平台的 Secret Store 建立 secret：

    MARKET_PULSE_REDIS_URL

2. 將該 secret 映射到 job environment。以 GitHub Actions 為例：

    env:
      MARKET_PULSE_REDIS_URL: ${{ secrets.MARKET_PULSE_REDIS_URL }}

3. 執行同一個 wrapper：

    powershell -NoProfile -ExecutionPolicy Bypass -File regression\td03_run_staging.ps1

不同 CI 平台的 secret 語法可能不同，但變數名稱應維持：

    MARKET_PULSE_REDIS_URL


三、安全注意事項
-----------------

- 不要將含密碼的 Redis URL 貼到對話、issue、commit、shell history 或 log。
- 不要把 URL 寫入 `.env` 後提交 Git。
- staging 與 production 必須使用不同的 Redis instance、credential 與 namespace。
- wrapper 不接受 URL command-line argument，避免 URL 出現在 process command line。
- wrapper 執行完成後會將四個 shared mode flags 回復為 `local`，再執行 rollout gate。
- wrapper 不會修改 `Procfile`、`render.yaml`、production environment 或 worker 數。


四、目前 TD-03 狀態
-------------------

workspace 本機替代 staging 的 real Redis contract、production shared-mode、雙 process HTTP
canary、fault injection 與 rollback probe 已完成；這些不等同正式 provider rollout。

五項正式 rollout 條件目前均未宣稱完成，仍需：

1. 正式 provider 的 Redis／Valkey staging URL；
2. provider-native backup／restore 證據（本機 RDB rehearsal 已完成，但不替代 provider evidence）；
3. observation period；
4. 人工 rollout approval；
5. production multi-worker rollout。

在上述條件完成前，production 維持 shared modes=local 與 `--workers 1`。
