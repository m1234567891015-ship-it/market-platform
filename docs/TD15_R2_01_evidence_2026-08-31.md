## Three-way evidence

### 1. CSS static and cascade evidence

- 8 個目標在 post-R1 manifest 均為 `retain-grouped-or-compound-review`，但整個 stylesheet 不進 production CSS cascade。
- 目標包含 grouped selectors、`.wide`／`.is-active` compound selector 與 820／560／1100 responsive blocks；這些 branch 只存在於不可載入的 legacy file，不會與 production split CSS 形成 live cascade。
- production split CSS 的 65 個 grouped blocks 不在本批；其中 derivatives overview、US ETF detail、US sector positive/negative、futures snapshot active 等保留項目沒有被刪除。

### 2. HTML／runtime／static whitelist evidence

- 21 個 HTML 只載入根目錄 `styles.css` 與 `split-01.css`～`split-07.css`，沒有 `assets/styles.css`。
- `market_config.py` 的 `ROOT_STATIC_FILES` 不包含 `assets/styles.css`；`routes_system.py` 的 asset route 只接受 `ASSET_STATIC_FILES`，不會提供該 CSS。
- post-R1 literal scan 對目標候選沒有 HTML／JS／Python direct usage；不修改任何 live selector、HTML、JS 或 runtime。

### 3. Page／interaction evidence

- Scope 固定為 21 頁、94 條 interaction steps。
- 由於目標檔案不可由目前應用載入，刪除不改變 production cascade；不更新 baseline。
- 若 full verify 出現未分類 DOM／pixel／interaction 差異，停止後續 TD-15 批次並以本批精確 diff 回復。
